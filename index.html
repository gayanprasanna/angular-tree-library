✨ Features

🎯 Smart Selection

Single or multiple node selection with checkboxes. Programmatic control over selections.

🔍 Powerful Search

Real-time search and filtering with customizable placeholders and search logic.

⚡ Lazy Loading

Load child nodes on-demand for better performance with large datasets.

🎨 Customizable UI

Configurable icons, animations, and control panels to match your design.

🛠️ Programmatic Control

Expand, collapse, and select nodes programmatically with simple API methods.

📱 Responsive Design

Works beautifully on desktop, tablet, and mobile devices.

📦 Installation

Install the package from npm:

npm install gp-tree-view

Basic Usage

import { NgxTreeComponent, TreeNode, TreeConfig } from 'gp-tree-view'; // In your component treeNodes: TreeNode[] = [ { id: '1', label: 'Root Node', hasChildren: true, children: [ { id: '1-1', label: 'Child Node 1' }, { id: '1-2', label: 'Child Node 2' } ] } ]; treeConfig: TreeConfig = { showCheckboxes: true, searchable: true, allowMultipleSelection: true };

🎮 Programmatic Control

Control your tree programmatically with these methods:

// Expand/collapse all nodes treeComponent.expandAllProgrammatically(); treeComponent.collapseAllProgrammatically(); // Control specific nodes treeComponent.expandNodeById('node-id'); treeComponent.selectNodeById('node-id'); // Get selected nodes const selected = treeComponent.getSelectedNodes();
